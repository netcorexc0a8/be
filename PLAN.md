# План: калькулятор детской смеси

Дата: 2026-10-02 · Для личного использования · Связанные файлы: [architecture.md](architecture.md), [CLAUDE.md](CLAUDE.md), [prototype/index.html](prototype/index.html)

## Описание проекта

Офлайн-приложение для телефона, которое считает, сколько миллилитров готовой смеси нужно ребёнку в сутки и сколько давать за одно кормление.

Входные данные: дата рождения, текущий вес, калорийность смеси (ккал на 100 мл готовой смеси), число кормлений в сутки (одно значение или диапазон).

Методика:

```
норма         = 115 ккал/кг (0–6 мес.), 110 ккал/кг (6 мес. и старше)
ккал_в_сутки  = целая часть (норма × вес_кг)
порции       = округлить до десятых (ккал_в_сутки / ккал_на_100мл)
мл_в_сутки    = порции × 100
мл_за_кормление = округлить до целого (мл_в_сутки / число_кормлений)
```

Эталонный пример: 5700 г, 3 мес., NAN Optipro 67 ккал/100 мл, 6–7 кормлений → 655 ккал → 9,8 порции → **980 мл/сутки** → **163 мл** (6 кормлений), **140 мл** (7 кормлений).

Ключевые решения (2026-10-02):
- только для себя: без сервера, без аккаунтов, данные на телефоне;
- PWA (веб-приложение, сохраняемое на домашний экран), работает без интернета;
- округление строго по шагам методики пользователя (ккал целым, порции до десятых, за кормление до целого мл);
- дизайн и состав экрана как в утверждённом прототипе.
