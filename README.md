# Калькулятор детской смеси

Личное офлайн-приложение для телефона: считает, сколько миллилитров готовой смеси нужно ребёнку в сутки и сколько давать за одно кормление.

Пример: 5700 г, 3 месяца, NAN Optipro (67 ккал/100 мл), 6–7 кормлений → 980 мл в сутки, 163 / 140 мл за кормление.

## Установка на телефон

Приложение публикуется на https://netcorexc0a8.github.io/be/

1. Откройте ссылку в Safari (iPhone) или Chrome (Android).
2. iPhone: «Поделиться» → «На экран „Домой“». Android: меню ⋮ → «Установить приложение».
3. После первого открытия приложение работает без интернета. Данные хранятся только на этом телефоне.

## Запуск для разработки

```
npm install
npm run dev     # приложение на http://localhost:5173
npm run check   # проверка типов, тесты и сборка
```

Расчёт ориентировочный. Нормы и объёмы согласуйте с педиатром.
